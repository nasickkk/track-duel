# TRACK DUEL

Браузерный 3D FPS-тренажёр трекинга с дуэлями **1 на 1**, HP, препятствиями, джамп-падами и **редактором собственных арен**.

> **Статус: прототип (v3.0).** Есть одиночная тренировка и экспериментальный режим P2P через PeerJS. Полноценной серверной защиты, постоянных аккаунтов, рейтинга и честной серверной симуляции **ещё нет**.

## Играть

После включения GitHub Pages: `https://nasickkk.github.io/track-duel/`

В GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**. Публикация может занять несколько минут.

## Возможности

- WASD — движение, мышь — прицеливание, ЛКМ — трекинг-огонь.
- Раунды 1v1 с 100 HP, счётом и PvE-ботом для тренировки.
- Укрытия, платформы и джамп-пады.
- **Map Creator**: размещение и изменение объектов, точки появления, импорт/экспорт JSON, локальное сохранение карты. Карта передаётся гостю при подключении к хосту.
- **V** — настройки размера и положения оружия, чувствительности и FOV.

Откройте `index.html` в современном браузере (для загрузки Three.js и сетевого подключения требуется интернет). Для сетевой дуэли оба игрока открывают один и тот же опубликованный сайт: один создаёт комнату и отправляет код другому. P2P через NAT/фаервол может не установить соединение в некоторых сетях.

## Дорожная карта

1. Авторитетный игровой сервер, фиксированный tick-rate, интерполяция и коррекция сетевой задержки.
2. Регистрация и вход через защищённый backend, надёжное хранение хешей паролей, rate limiting и серверная авторизация.
3. Постоянная база данных: победы в раундах, accuracy и мини-лидерборд.
4. Сохранение и публикация пользовательских карт с модерацией.
5. Низкополигональные скины, насмешки, фразы и другие косметические элементы.

**Важно:** GitHub Pages — статический хостинг. Для постоянных аккаунтов, доверенной статистики и честного подсчёта попаданий нужна отдельная серверная часть с базой данных. Не храните пароли, токены или секреты в этом репозитории.

## Разработка

Текущая версия — самостоятельная страница `index.html` (Three.js + PeerJS из CDN). В будущем код будет разделён на `client/`, `server/`, `shared/`, тесты и документацию.

### Авторские права и сторонние библиотеки

Используются Three.js и PeerJS, подгружаемые через CDN. Их лицензии и версии регулируются соответствующими upstream-проектами.
