# TRACK DUEL 5.3: игра 1v1 через Radmin VPN без Render/Cloudflare

Прототип LAN-режима рассчитан на двух друзей в одной виртуальной сети Radmin VPN.
Клиент и WebSocket-сервер доступны **с компьютера хоста через один HTTP-адрес**.

## Хост (Windows)

1. Подключи Radmin VPN и создай сеть. Друг должен присоединиться к той же сети (https://www.radmin-vpn.com/ru/help/).
2. Скачай обновлённый ZIP https://github.com/nasickkk/track-duel/archive/refs/heads/main.zip и распакуй полностью. Убедись, что `index.html` находится в корне, рядом с папкой `server`.
3. В Radmin VPN скопируй **свой IPv4** (обычно `26.x.x.x`), не адрес друга и не адрес провайдера.
4. Открой папку `server`, запусти **start-radmin.bat** и введи свой Radmin IPv4.
5. Если Windows спросит разрешение на входящие соединения Node.js, разреши для сети Radmin VPN. Не отключай весь брандмауэр.
6. В консоли появится URL `http://ВАШ_RADMIN_IP:10000/play`. Открой его в браузере хоста. Не используй для этого режима HTTPS-ссылку GitHub Pages.
7. Выбери режим **Через сервер (WebSocket)**: URL должен подставиться автоматически. Нажми «Создать комнату».
8. Отправь другу адрес `http://ВАШ_RADMIN_IP:10000/play` и код комнаты либо ссылку «Скопировать ссылку другу». На HTTP браузер может запрещать Clipboard API; в таком случае появится окошко ручного копирования.

## Друг

1. Подключается к той же сети Radmin VPN.
2. Открывает в своём браузере адрес хоста `http://ВАШ_RADMIN_IP:10000/play`.
3. Нажимает «Войти» с кодом комнаты (или открывает приглашение — код подставится).
4. Никакой локальный Node.js ему устанавливать не нужно.

## Проверка

- У хоста: `http://ВАШ_RADMIN_IP:10000/health` должен вернуть `"ok":true`.
- У друга: открой тот же `/health`. Если не открывается, в PowerShell попробуй `Test-NetConnection ВАШ_RADMIN_IP -Port 10000`. Если `TcpTestSucceeded: False`, проверь что оба в одной сети Radmin VPN, правильность IP, работу server/start-radmin.bat и правило брандмауэра для входящего TCP 10000 на интерфейсе Radmin VPN.
- Если Node пишет `EADDRNOTAVAIL`, введён неправильный IPv4 или адрес не назначен компьютеру хоста.
- Если `EADDRINUSE`, уже запущен обычный `start-windows.bat` или другая программа заняла порт 10000. Закрой прежний сервер и снова открой `start-radmin.bat`.
- Если страница открылась, но 3D сцена не работает, открой F12/Console: Three.js по-прежнему загружается из CDN, нужен интернет.
- Для получения настоящего RTT попроси друга запустить игру; HUD показывает время до хоста и круговой RTT через Radmin.

## Почему не GitHub Pages

GitHub Pages открывается по `https://`. Браузер блокирует обращение HTTPS-страницы к незащищённому `ws://` как mixed content (https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Mixed_content).
Для LAN нужно открыть именно `http://ВАШ_RADMIN_IP:10000/play`: клиент и WebSocket находятся на одном локальном origin.

## Ограничения безопасности

- HTTP без TLS не подходит для общедоступного интернета; в этом режиме трафик проходит через приватную виртуальную сеть Radmin VPN. Не используйте этот адрес для секретных данных.
- Релей не авторитетен: попадания и часть синхронизации по-прежнему рассчитывает клиент-хост. 128 Гц относятся к локальной физике, не к серверной симуляции.
- Запуск на хосте привязан только к выбранному IPv4 адаптера (BIND_HOST), чтобы не публиковать порт на всех интерфейсах.
- При завершении окна `start-radmin.bat` игра перестанет быть доступна.
- Если у Radmin VPN между друзьями статус Relay/TCP вместо Direct, пинг может быть выше; сравните показания RTT во время игры.
